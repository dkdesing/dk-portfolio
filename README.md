# DK Desing Portfolio — folder system

Редагування:
- data/site.json — головні тексти, телефон, email
- data/projects.json — папки портфоліо
- data/team.json — команда
- public/projects/... — фото проєктів
- public/team/... — фото команди

Після змін: Commit + Push у GitHub Desktop.


## Прихована адмін-кнопка

На головній сторінці набери на клавіатурі: `dkadmin` — зʼявиться кнопка `Адмін`.
Щоб сховати кнопку — натисни `Esc`.


## Світла / темна тема

На сайті додана кнопка перемикання теми. Вибір зберігається у браузері.


## Переклад

Кнопка EN/UA перемикає українську та англійську версію. Тексти англійською зберігаються у data/site.json, data/projects.json, data/team.json.

## Прихований адмін

Кнопка адмінки прихована. На сайті набери `dkadmin`, щоб вона зʼявилась. На сторінці /admin також треба ввести код `dkadmin`.
